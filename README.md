# X4 存档修改器

本地中文存档修改器，使用浏览器界面，聚焦大型存档的完整解析、分页浏览和通用属性编辑。

当前 `main` 分支为网页版；已发布的 [v0.1.0](https://github.com/Tartarshia/X4SaveEditor/releases/tag/v0.1.0) 保留桌面第一版。

双击 `启动X4存档修改器.cmd` 或 `start.cmd`，自动在默认浏览器打开 **http://127.0.0.1:8765**。需要 Python 3.11 或更新版本，应用后端仅使用 Python 标准库，前端无框架、CDN 或外部服务依赖。

服务仅监听 `127.0.0.1`。关闭浏览器标签页不会停止服务；在启动窗口按 `Ctrl+C` 退出。端口冲突时可运行 `python web_server.py --port 8766`。原 Tkinter 界面仍可通过 `start-desktop.cmd` 启动，需要 Python 的 Tkinter 组件。

## 使用

1. 点击“打开存档”：选取自动发现的存档、粘贴本机完整路径，或用文件选择器导入 `.xml.gz` / UTF-8 `.xml`。首次后台解析并建立磁盘索引；同一文件未变时复用缓存。
2. 双击节点进入子节点，或使用标签统计跳转。支持标签、ID 精确查询、节点编号，以及名称 / macro / owner 等摘要内容的包含查询。
3. 选中节点查看属性与最多 16 KiB 的原文片段。修改属性后点击“暂存”，先加入待修改清单，可逐项撤销。
4. 点击“导出新存档”，核对修改数量与文件名。工具在工作区 `.local/exports/` 下生成独立新文件，完整回读校验后提供下载，不覆盖原存档。

每页最多 200 个节点，下一页使用节点游标；“返回”可回到上一页或上一个查询。大部分操作在后台进程执行，窗口不承担整份 XML 的解析。

左右面板之间的分隔条可拖动，也可聚焦后使用左右方向键调整；宽度保存在当前浏览器。窄窗口自动上下排列，表格与原文可独立滚动。修改清单只保存在当前标签页，刷新或关闭会丢失；有待修改内容或运行中的任务时，浏览器会提示离开。

## 进度显示

底部在空闲时只显示“就绪”，隐藏动态进度线。执行任务时显示当前阶段与耗时：解析显示已读取 MiB 与节点数，建立索引显示阶段说明，导出显示百分比，回读校验显示已校验节点数。动态线只是忙碌提示，不代表百分比；文件选择器导入显示实际传输到本机的百分比。

## 第一阶段范围

- 全部 XML 元素均解析并索引，不限于玩家资产。原始 ID 保留，暂不翻译。
- 所有已有属性都可通用编辑；暂不添加 / 删除节点，不提供自动关联的金钱、库存或船员业务按钮。
- XML 结构校验不等于游戏语义校验。例如摘要里的 money 可能不是实际账户字段；仅改一处不保证生效。
- 原始文本、注释、CDATA 和空白字节完整保存。非属性文本目前只供片段查看。
- 尚未在游戏内验证修改后的存档；自定义导出文件名也不保证直接列入游戏槽位。退出游戏后自行备份及管理槽位，再进入游戏核验。

## 性能与缓存

SQLite 保存父子关系和标签索引；XML 解压后保存在 `.cache`，按需定位读取。第一次需要解析完整文件并构建索引，后续打开及分页更快。

完整索引以磁盘空间换内存和查询响应：每份存档会保存一份解压 XML 和一份数据库。名称包含查询需要扫描摘要表，比标签 / ID 精确查询慢，但在后台执行。

缓存和导出测试数据不上传。关闭程序后可删除整个 `.cache` 与 `.local`，不会影响原始存档。强制退出长任务可能留下没有 `meta.json` 的不完整缓存目录或 `.x4-export-*.tmp` 临时文件；确认程序关闭后可清理。启动不自动删除其他实例可能正在使用的文件。

文件选择器会按块把文件写到本机 `.local/imports/`，额外保留一份导入副本。优先从存档列表或完整路径打开，可避免这份复制并复用同一份缓存。浏览器只接收一页节点或一个原文片段，不加载整份 XML。

导出使用低压缩级别，优先速度，生成的 `.gz` 可能大于原始存档。相同加载快照可反复导出；清单仍保留，原文面板显示的是加载时原始内容。

## 验证

```powershell
python -m unittest discover -s tests -v
python benchmark.py "你的存档.xml.gz" --fresh --export
```

可选桌面冒烟测试：`python tests/gui_smoke.py`。可选浏览器冒烟测试：本机已有 Playwright 和 Microsoft Edge 时，先启动服务，再运行 `node tests/web_smoke.cjs`；可用环境变量 `X4_PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块。该检查覆盖导入、分页、分栏拖动、属性修改与撤销、导出下载、窄窗口布局和空闲进度隐藏，不是应用运行依赖。

性能脚本在 `.local` 写本机报告及测试副本。它对完整大存档执行一次属性修改、回读全部节点、独立逐块比较未改动的原文，以及验证原存档 SHA-256 未变化。

实际大存档性能与验证结果见 [PERFORMANCE.md](PERFORMANCE.md)，同类项目分析见 [RESEARCH.md](RESEARCH.md)。工具不修改游戏安装目录。
